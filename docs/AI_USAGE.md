# AI 기술 활용 내역 (분석보고서 'AI 기술 활용' 항목용)

공모전 준수사항(AI 활용 1~5항)에 따라 사용 서비스, 활용 범위, 주요 프롬프트를 기록합니다.

## 사용 서비스

| 서비스 | 모델 | 용도 |
|---|---|---|
| Claude Code (Anthropic, 데스크톱 앱) | Claude Opus 5.5 | 주제 선정 논의, 데이터 수집 자동화 스크립트, 분석 파이프라인 코드 작성, 시각화, 보고서 초안 |

## 활용 범위

1. **주제 탐색**: 공모전 공고문과 양식을 읽고 주제 후보 3개를 비교한 뒤 '경사 반영 보행 접근성'을 선정
2. **데이터 수집 코드**: 공개 데이터 포털의 다운로드 경로 확인, FABDEM 타일 부분 다운로드(HTTP Range), OSM 추출본 처리 코드 작성
3. **분석 코드**: 링크 경사 계산, Tobler 보행속도 모형, 다중출발 다익스트라, 행정동 집계, 신규 정차지점 탐욕 최적화 코드 작성
4. **시각화**: 지도·그래프 코드 작성
5. **보고서 초안**: 분석 결과를 바탕으로 한 보고서 문장 초안

## 검증 내역 (분석 중 AI와 함께 수행 — 제출 전 참가자가 직접 재확인)

- DEM 표고를 알려진 지점(남산·여의도·서울시청·관악산·북한산)과 대조
- 보행속도·임계시간 등 가정값의 근거 문헌 확인
- 결과 지도에서 상위 행정동이 실제 경사지 주거지인지 확인
- 민감도 분석(기준시간 5·8·10·15분)으로 결론이 가정에 좌우되지 않는지 확인

## 입력하지 않은 데이터

개인정보·위치정보·비공개 자료는 AI 서비스에 입력하지 않았습니다. 사용한 데이터는 모두 공개 데이터입니다.

## 주요 프롬프트

1. "(공모전 공고 URL, 참가신청서·분석보고서 양식 첨부) 이 대회 나가려고 하는데, 어떤 주제로 할까?"
2. "추천 주제로 경사 심한 구 몇 곳만 해줘"
3. "지금 어떤 상황인지 설명하고 계속 진행해줘"
4. "(보행속도·경사 기준·DRT 현황 출처를) 이건 어떻게 확인해?" → AI가 법령·경찰청 공지 원문을 찾아 대조, 보행속도를 현행 기준 0.7m/s로 수정 후 재분석
5. (이후 프롬프트를 여기에 추가)

## 분석 과정에서 바뀐 설계 (AI가 결과를 보고 제안·수정, 참가자 검토 필요)

- 처음 지표(평지 대비 경사로 늘어난 도보시간)는 효과가 작게 나와, 법정 경사로 기준(1/12)을 적용한 '무장애 경로' 지표로 전환
- 구 선정 기준을 산지 등산로가 섞이지 않도록 '주거지 보행로' 기준으로 변경
- 정차지점 신설 시뮬레이션의 효과가 작다는 결과를 그대로 보고하고, 구역형 DRT 비교를 추가
